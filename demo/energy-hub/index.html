Demo Energy Hub

A synthetic energy-event API for QA scenarios. Events are kept in memory and cleared when the demo restarts.

Submit an energy event

Enter the four event fields as JSON. The API validates the original text you submit.

Retrieve an event

Use the event ID from a successful submission.

A new event returns 201. An equivalent replay returns 200. Conflicting content returns 409. Invalid fields return 422.
